# Code of Conduct

Fast Spider is a technical project for safe, user-controlled automation. Contributors are expected to keep discussion respectful, practical and focused on improving the project.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while asking for concrete evidence.
- Keep issues and pull requests focused on reproducible facts.
- Respect user privacy, local machine boundaries and credential safety.
- Redact logs, screenshots and examples before sharing them publicly.

## Unacceptable behavior

- Harassment, insults or discriminatory language.
- Publishing private credentials, tokens, cookies, machine identifiers or private environment details.
- Encouraging unsafe deployment patterns that bypass the documented security model.
- Repeatedly derailing technical discussions.

## Enforcement

Maintainers may edit, hide or remove content that violates this code of conduct. Repeated or severe violations may result in blocked participation in the project.

Security-sensitive reports should follow `SECURITY.md` instead of public issue threads.
