# Support

Fast Spider is maintained as an open-source project. Community support is
provided through GitHub and is best-effort rather than a guaranteed service.

## Before asking for help

1. Read the [Getting Started guide](docs/getting-started.md),
   [configuration reference](docs/configuration.md) and
   [security model](docs/security-model.md).
2. Search existing issues for the error message or affected capability.
3. Reproduce the problem with the latest released version when practical.

## Where to ask

- Open a bug report for a reproducible defect.
- Open a feature request for a concrete use case or improvement.
- Use a focused pull request for documentation or code changes.

Include the Fast Spider version, operating system, deployment type, expected
behavior and minimal reproduction steps. Redact tokens, credentials, machine
identifiers, private paths, hostnames, logs and screenshots before posting.

Do not use public support channels for suspected vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.
