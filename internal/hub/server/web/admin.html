Node Setup

  1. 生成令牌：进入“连接令牌”创建并复制明文。

Connection Token

连接令牌教程

令牌用于登记新设备，不是 MCP OAuth 凭据，也不是 Direct API Key。

01

创建并复制

设置名称和有效期后生成；明文只展示一次，请立即保存到密码管理器。

02

仅在客户端使用

把令牌填入 Node UI 的连接表单。不要把连接令牌发给 AI 或写进提示词。

03

用完即撤销

设备登记成功后可撤销令牌；撤销不会影响已登记设备的正常运行。

Account Security

账户安全

当前登录账户：{{.Username}}。修改密码会保留当前浏览器，并立即退出其他后台会话。

Security

账户安全教程

密码、连接令牌和直连 Key 分开管理，任何一个泄露都应立即撤销或更换。

  • 首次登录后立即把默认密码改成唯一的强密码。
  • 直连 Key 按最小权限、最短有效期创建，使用完立即撤销。
  • 不要在提示词、截图、日志或 Git 仓库中粘贴真实 Token。

  3. 授权完成后先调用 initialize 和 tools/list。
